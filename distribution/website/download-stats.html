What a count means

A count is a successful full-file GET response from the Windows or Android download route, including direct links. Metadata checks, prefetch requests and all partial/Range requests are excluded. A download manager that uses only partial requests will not be counted.

Repeat full downloads and automated requests can count again. Interrupted downloads may have already started. Live counts begin when tracking is enabled. Recovered historical file requests appear separately because their measurement differs. A recording failure can undercount without blocking the download.

Only aggregate platform counts, coverage dates and source metadata are stored by this report. No download cookies, visitor IDs, IP addresses, email addresses or user-agent logs are added.
