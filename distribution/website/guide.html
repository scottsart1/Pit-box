Android setup — no laptop required

Download Android APK

The signed APK supports Android 7 or later on 64-bit ARM and x86 devices with 4 KB memory pages. Devices using 16 KB memory pages are not supported by this release. This is a direct download, not a Google Play listing; the Windows installer does not install on Android.

Already using the test app? The release package (com.yourpitbox.app) installs separately from the test package (com.yourpitbox.app.debug) and starts with its own library. Do not uninstall the test app or expect its history and keys to move automatically. Keep a backup, then use beta history transfer when neither device is recording. Never uninstall an existing app to force a signing-key mismatch.
  1. Download the APK from this site and check the SHA-256 on the download page. Open it; if Android asks, grant installation permission to the browser or file manager you used, then turn that permission back off after installing. Keep Play Protect enabled. Do not bypass an incompatible-device or security-policy block.
  2. Connect the Android device and your PS5 or gaming PC to the same private home network. Open Your Pit Box on the tablet; the laptop is not required for the native Android engine.
  3. Keep setup step 2 open. Enter its UDP IP Address and port in the game; set telemetry On, broadcast Off and format 2026. The usual port is 20777; use the value shown. Connection also has these details.
  4. Start an on-track session and confirm Receiving telemetry. A listening socket or a saved lap chart alone does not prove that fresh packets are arriving.
  5. For radio, save and test the provider key in Connection, allow Android microphone access, and enable voice in the app. Speech services need an OpenAI key and internet access; the dashboard can receive telemetry without voice. The optional billing and key creation instructions apply to either app.
  6. Check microphone input separately from the reply. If the app hears input but you hear nothing, check the selected output, media volume and Bluetooth routing. A key test does not verify the microphone or speaker.

Future updates to the release app use the same permanent signing identity. Install a verified release update over the release app; do not remove its saved data.

Before a full-length race, check your microphone, selected speaker or headset, wake phrase and background settings on the device you will use. A short radio check verifies that setup, not every Bluetooth device or power-saving mode.

Keep the Android app visible and the screen awake during live racing. Screen-off reception is best-effort: Android Doze and manufacturer battery management can suspend network access even while the app's running notification is present. If you choose background use, review the app's battery restrictions in Android Settings and test a full session on your device first. Do not rely on a short packet check as proof of uninterrupted screen-off recording.
1 Windows walkthrough

Download the Windows installer

  1. Open the Download section and select Download for Windows.
  2. A prompt offers to take your email so you hear about new versions. Leave one and choose Notify me and download, or choose Skip — just download. Either way the download starts.
  3. Save PitWall-Setup.exe. The download size varies by release.
There is no code and no account. The download is the complete application. If you installed a version from before it went free, run this installer over the top; your sessions and settings are kept.
2 Optional radio setup · both platforms

Turn on API billing

This is optional for telemetry and local strategy. If you are starting without AI or voice, go straight to Windows installation, or return to Android setup.

  1. Sign in at the OpenAI Platform. This may use the same login as ChatGPT, but it has separate billing.
  2. Open the API billing overview and add payment details or buy API credits.
  3. Review the auto-recharge setting before confirming. Leave it off unless you want automatic top-ups; if you turn it on, set a monthly recharge limit you are comfortable with.
ChatGPT Plus, Pro, or Business does not include API usage. Your Pit Box's model-backed radio calls are charged to the API account connected to your key.
3 Optional radio setup · both platforms

Create and copy your API key

  1. Open the API keys page.
  2. Select Create new secret key, name it Your Pit Box, choose All permissions for the simplest compatible setup, and create it.
  3. Copy the complete secret immediately and keep it private. OpenAI only shows the full value when it is created.
If you lose the key, create another one. Do not send it by email, put it in a screenshot, or share it with Your Pit Box support.
Prefer Claude, DeepSeek or Kimi? The engineer's reasoning can run on those too: paste that provider's key on the Connection tab after setup and pick it under Engineer runs on. The spoken radio still uses OpenAI, which is why this guide sets an OpenAI key up first.
4 Windows

Install Your Pit Box

The current Windows installer is unsigned. Windows may identify an unknown publisher or block it under your security policy. Verify the SHA-256 shown on the download page.
  1. Run PitWall-Setup.exe and follow the installer. It installs for your Windows account, so it does not need an administrator password.
  2. Leave Launch Your Pit Box selected at the end. The Welcome to Your Pit Box window opens.
  3. Paste your OpenAI API key and select Continue — or select Skip for now and add it later.
The welcome window appears once. The API key can be added or changed at any time under Connection, but entering it here is the shortest path. Nothing is activated and nothing is sent anywhere: the key is stored only on this PC.
Is the window called Activate Your Pit Box, with an activation-code field? Close that older window and download a fresh PitWall-Setup.exe from the Download section. Run it over the existing installation using the same Windows account; do not uninstall or delete your data folder. Your sessions and settings are kept, and the current version needs no activation code. Start Your Pit Box from the Start Menu after setup finishes.
Your Pit Box takes 20–30 seconds to start, every time. After the welcome window — and on every launch from then on — there is a pause before the dashboard opens while the strategy engine, telemetry socket and audio device come up. It opens the browser itself once it is ready, so there is nothing to click and nothing has gone wrong. Allow longer on the first start after installing, or if the PC is busy with something else.
5 Your Pit Box

Copy the PC address and check any saved key

If you have not configured AI or voice, skip the key test and copy the telemetry address. You can add a key later without reinstalling.

  1. Your Pit Box starts its local server and opens the dashboard in your browser by itself. Give it 20–30 seconds — it loads the strategy engine, opens the telemetry socket and starts the audio device before the dashboard appears. Nothing is wrong during that wait. Then select the Connection tab.
  2. Under AI provider & API keys, keep OpenAI selected as the key being managed and select Test saved key. A successful test confirms that the saved OpenAI API key can authenticate with OpenAI.
  3. Copy the large address under Enter this UDP IP on PS5 and note port 20777. The screen is labelled for PS5, but the same address also works for a second PC running the game.
Use the recommended private LAN address, usually beginning 192.168. or 10., when the game runs on a PS5 or a second PC. Never enter 127.0.0.1 or 0.0.0.0 there. The one exception: if F1 25 runs on this same PC as Your Pit Box, use 127.0.0.1 in the game instead of the address shown here.
6 Game settings — PS5 / PC

Send 2026 telemetry to Your Pit Box

  1. In F1 25: 2026 Season Pack, open Settings → Telemetry Settings. The menu is the same on PS5 and PC.
  2. Set UDP Telemetry to On.
  3. Set the UDP IP Address: on a PS5 or a second PC, enter the address Your Pit Box recommended in the previous step; if the game runs on this same PC as Your Pit Box, enter 127.0.0.1 instead. Set UDP Port to 20777, and select UDP format 2026.
  4. Start or join an on-track session. Return to Your Pit Box and wait for the badge to say Receiving telemetry.
Listening is only halfway there. It means the app opened the socket. Receiving telemetry and fresh packet activity show that valid game packets are arriving.
For a Windows receiver on your private network: if Windows Firewall prompts, allow Your Pit Box on private networks so your PS5 or another PC can send telemetry. Do not disable the firewall. For a same-PC setup, send to 127.0.0.1. An Android receiver uses the tablet's own address, not the laptop's.
7 First live check

Ask the engineer while you drive

  1. Open Drive in Your Pit Box and select Test providers. Continue when it reports All configured providers ready; this live check uses a small amount of API credit.
  2. With the PC microphone and speakers ready, say “Mark, what is the gap ahead?” in one sentence. You can also say “Mark,” wait for the beep, and then ask.
  3. For push-to-talk on PS5, first map L3 to UDP Action 1 in the game's control settings, then use the L3 → UDP Action 1 radio card in Your Pit Box and select Calibrate. On PC, bind the equivalent action in the game's own control-bindings screen, then calibrate that same input in Your Pit Box.
You are ready. Your Pit Box continues receiving telemetry on the PC while the game stays full-screen on PS5 / PC. Exact gaps and car-state questions are answered locally; model-backed strategy and voice calls use your OpenAI API key.
Device-to-device history transfer · beta

Copy completed sessions between devices

History transfer is manual, not automatic cloud sync. Each device keeps its own library. Pairing does not sync keys, microphone permissions or a live race. This feature is beta: keep the originals until you have checked the receiving library.

  1. Finish the receiving device's recording and stop its telemetry listener. Keep both apps open on the same private network and enable Wi-Fi transfers on both.
  2. Use the displayed QR code or invitation to pair the devices you trust. Then select completed sessions on the sender from the receiving app.
  3. Start with a small selection. Very large libraries may exceed archive limits or time out during preparation; a larger timeout alone does not make an oversized archive importable.
  4. Version 4.10.1 adds transfer stages on both devices; older builds may show less detail. Preparing packages the history; sending moves the file; checking verifies it; importing saves it. A full send bar is not confirmation that the history is imported.
  5. Wait for completion on the receiving device, then check its Library. Matching sessions already present are skipped. Only available history is copied; previously pruned samples cannot be reconstructed.
  6. Turn transfers off and restart telemetry on the device you want to use for the next race. Check the game's UDP destination again if switching from laptop to tablet.
It timed out, or I want to play now

Do not delete your library, uninstall the app or repeatedly start new copies. Check both devices first: the sender may still be preparing the same export. Retry the existing failed transfer when appropriate, or choose a smaller batch after it has stopped. To pause transfers, turn Wi-Fi transfers off and wait until no job is preparing, downloading or importing before restarting telemetry. An import already saving history must finish safely; do not force-close the app.

What is actually transferred?

The selected sessions and their available history, traces and linked reference data are copied over the local network. This is not a complete device backup. API keys, private connection settings and microphone permissions stay on their original device. Keep a separate recoverable backup before replacing an app or making a major upgrade.

Telemetry transmission · beta

Forward live telemetry to another app or device

Optional UDP forwarding is separate from saved-session transfers and from receiving game telemetry directly. A forwarded packet is best-effort, not a delivery receipt.

  1. First confirm that the sending engineer shows Receiving telemetry from the game.
  2. In Connection → UDP forwarding, add the destination app's address and listening port. Prefer a trusted destination on the same private network.
  3. Enable that target and check the receiving app for fresh telemetry. The sender's packet count alone does not prove delivery.
  4. Avoid forwarding loops or sending both a direct and forwarded feed to the same receiver. If reception is unreliable, disable forwarding and point the game directly at the engineer you are using.

Beta forwarding does not copy your saved library, API keys or microphone permissions. Do not forward telemetry to a public address unless you intend to share it with that destination.

Quick fixes

If a check does not pass

The key test fails

Confirm that API billing is active, wait a few minutes after buying credits, and paste a newly created secret under Connection → OpenAI API key. Select Save key, then Test saved key. A ChatGPT subscription by itself is not API billing.

Your Pit Box says Listening

Start an on-track session. Recheck the receiving device's address in Connection, port 20777 and format 2026, then select Run diagnostics. Use the Android address for Android, the PC address for Windows, or 127.0.0.1 only when the game and engineer run on the same PC. Make sure both devices share the private network; for Windows reception, allow the app through the firewall on private networks without disabling protection.

Windows: the dashboard did not open

First, give it 20–30 seconds. Your Pit Box opens the browser itself, but only once the strategy engine, telemetry socket and audio device are up, so a launch that looks like nothing is happening is usually just a launch still in progress.

If it has been longer than that, leave Your Pit Box running and open http://127.0.0.1:8000 on that same PC. The address is local to the computer and is not a public website.

Windows: closing the browser did not stop Your Pit Box

That is deliberate. The dashboard is only a window onto Your Pit Box; the app itself keeps running so it can carry on recording telemetry and answering on the radio while the browser is closed. There is no console window and no tray icon, so nothing visible tells you it is still there.

To stop it, open the dashboard and use Quit Your Pit Box in the top-right corner. It finishes and saves any session being recorded first, then closes. Allow about 20 seconds for it to shut down fully before starting it again.

It asks for an activation code

That is an older version; the current download needs no code. Close its activation window, download a fresh PitWall-Setup.exe from the Download section, and install it over the existing version using the same Windows account. You do not need to uninstall first. Your sessions and settings are kept; do not delete the PitWallData folder.

After setup, launch Your Pit Box from the Start Menu rather than reopening an older downloaded copy. If an activation window still appears, contact support with the exact window title and installer filename. Do not include your API key.

For historical installs only: if you deliberately keep an earlier version and already have a code, the activation diagnostics check server reachability and whether that existing code is recognised, without using it up. They do not issue a new code and are not needed for the current download.
