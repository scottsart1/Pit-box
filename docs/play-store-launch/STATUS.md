# Google Play launch status

Updated: 16 November 2026

[PR #66](https://github.com/scottsart1/Pit-box/pull/66) merged into `main` at `4b9bc0e`. The Play candidate is Your Pit Box 5.8.0, Android version code 45. The existing direct-download APK is revision 44.

## Verified

- [CI run 43796390204](https://github.com/scottsart1/Pit-box/actions/runs/43796390204) passed the shared checks, unsigned bundle native ELF alignment, and the ordinary and 16 KB Android 16 x86_64 emulator flows. Both flows verified startup, driver switching and separate storage, UDP reception, fullscreen behavior, transfer controls, native Setup and Test Engineer, and session-report export. The 16 KB run checked a page size of 16,384 bytes.
- Physical Wi-Fi and paired-device history copying were outside this smoke test. A prior API 35 image crashed in the WebView 124 renderer. The green API 36 run does not resolve that older configuration. The Play-delivered upgrade path still needs a physical-device test.
- Play Console shows `com.yourpitbox.app` on a personal developer account. The internal track is inactive with a saved draft named Your Pit Box 5.8.0 • Internal test 45. The dashboard shows zero opted-in closed testers and production access is unavailable.
- [Key transfer run 43824953245](https://github.com/scottsart1/Pit-box/actions/runs/43824953245) used the GitHub `release` environment and generated the verified encrypted PEPK ZIP. On 16 November, Play accepted the import. The app-signing and upload certificate fingerprints shown in Play Console both match the existing direct-download APK. The app-signing gate is satisfied.
- [Signed bundle run 43825758058](https://github.com/scottsart1/Pit-box/actions/runs/43825758058) succeeded from `main` at `53b6329`. The AAB signer matches the registered upload certificate. SHA-256 `776f237eba749c23edac7d03db8d96c4fb69e40f98b87a59e3aa2ec919abcdd9`. Bundletool validated package `com.yourpitbox.app`, version code 45, target API 36 and `PAGE_ALIGNMENT_16K`. The AAB passed alignment checks for all 188 native libraries, and local bundletool ABI splits passed the ELF and ZIP checks for arm64-v8a and x86_64.
- Play accepted and optimized the AAB. Version 45 and English release notes are saved in the [internal release draft](https://play.google.com/console/u/0/developers/5430246558013811560/app/4972523618370534870/tracks/4700348206769510763/releases/2/review). The preview reports two nonblocking diagnostic warnings for missing deobfuscation mapping and native debug symbols. The release is awaiting internal rollout.
- The English listing, support details, artwork and the dedicated [privacy policy](https://yourpitbox.com/privacy.html) were saved in Play Console. The last saved app-content setup included IARC Everyone/PEGI 3, a target audience of 13 and older, and a Data safety draft that discloses that some user-configured provider traffic can use HTTP. See [asset provenance](ASSETS.md) and the [Data safety review](DATA_SAFETY.md).
