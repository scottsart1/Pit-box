# Screenshots

Every image here is a frame of the real application, captured from a running
build. Nothing is a mockup, a wireframe, or hand-edited markup.

## The data is synthetic

The race shown is invented. It is a 52-lap Silverstone Grand Prix with a
20-car field, generated by `tools/demo_broadcast.py` and sent to Your Pit Box as
genuine F1 2026 UDP packet structures, serialized with the same library the
game's output is parsed by. The receiver, parser, state layer, strategy
engine, analysis services and UI are all the real ones; only the car on the
other end of the socket is fake.

It is not a recording of any real session, and the driver names are the
current grid used as plausible labels, not results.

## Reproducing them

```bash
# 1. run the app against an isolated demo data root
python -m tools.demo_server

# 2. broadcast the synthetic race into it
python -m tools.demo_broadcast --port 20777 --seconds 600

# 3. capture
python -m tools.capture_screens --out docs/screenshots
```

`tools/demo_server.py` points `PITWALL_DATA_DIR` at `.demo-data/` so a capture
never reads or writes a real driver's saved sessions.

## The Hungaroring set

`07`, `08` and `09` come from the second scenario, `tools/scenarios.py::HUNGARORING`,
which exists for the demo video rather than for documentation. It is built
around one deliberately balanced call: P4 on 22-lap-old hards, sixteen laps
left, a quicker car 3.6 s behind on fresher mediums, at a circuit where
overtaking is hard enough that track position is worth defending.

| File | Screen | Notable |
|---|---|---|
| `07-hungaroring-decision.png` | Drive | The decision point; also the demo video's poster frame |
| `08-hungaroring-radio.png` | Drive, full height | The engineer's spoken answers in the radio feed, beside the three ranked plans they came from |
| `09-hungaroring-field.png` | Field | The field during the same moment |
| `15-promo-poster.png` | Drive | The opening frame of the captioned 45-second cut, caption bar included; it is the poster for that video, not a documentation shot |

Reproduce them with:

```bash
python -m tools.demo_server
python -m tools.demo_broadcast --scenario hungaroring --seconds 2400
python -m tools.capture_demo_video --base http://127.0.0.1:8010 \
    --out distribution/website/assets/pitwall-demo.mp4
```

The capture tool writes the stills as a by-product of recording the video, so
they are frames of the same session the video came from rather than a separate
run.

An earlier set showing the pre-4.2 single-page dashboard has been removed, so
every image here reflects the current build. The old files remain in git
history if they are ever needed.

### Lap Lab is not yet captured

Lap Lab is the one screen without an image here. The feature works - a lap
comparison against a strict reference returns aligned timing, and on a real
recorded session it produced a +0.182 s lap delta where the raw lap times
differed by 0.183 s. The demo capture session was interrupted and restarted
several times while the harness was being built, which left trace manifests
catalogued whose files were never finalized, so the comparison could not read
its telemetry.

Capturing it needs one uninterrupted demo run: start the demo server, let
`demo_broadcast` run without stopping it for at least four laps of real time
so the traces are dense, stop the broadcast once, restart the server so the
session finalizes cleanly, reprocess, then capture. Do not clear the data root
or kill the broadcaster mid-lap in between.

## Honest limitations visible in these images

These were left as they are rather than staged around, because they are the
product telling the truth:

- Values the game did not supply read **Unavailable**, never zero. Opponent
  cars in particular do not expose the player's full sensor set.
- A session still recording shows official classification as unavailable,
  because that data is only final once the session is.
- The Connection Center shows the capture machine's own private LAN address
  and adapter. That is what a user sees; it is a `192.168.x.x` address that
  means nothing outside that network.
