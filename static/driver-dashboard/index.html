DESIGN EXPLORATION

Built for the next glance

Six directions for a new Driver Dashboard tab. All use the same simulated session, so you can compare what each layout makes easiest to read.

A shared racing language

Flags stay at the top, with both a color and a written instruction. Gaps explicitly say ahead or behind. Lap deltas use signed numbers and faster/slower labels. Customization happens before entering race mode.

Reference points

Lovely Dashboard — instrument hierarchy, multiple display formats, and focused modules.

RaceLab — readable relative timing, standalone flag alerts, and configurable layouts.

SimHub Dash Studio — independent, repositionable information surfaces.

This is a UI prototype. Values, flag scenarios, and messages are scripted examples, not live telemetry or race-control instructions. These controls do not change the car or race strategy.
